先選模型、輸入密碼

這個靜態版每次開啟都要先解鎖：選一組你已經儲存的模型，輸入你的密碼，才能開始使用。金鑰只會送到你選的那家廠商，不會經過任何其他伺服器。

忘記密碼只能重置：重置會清除全部已存的模型設定與金鑰（照片與衣櫃不會被刪），之後要重新新增模型、重新設密碼。

沒有模型可以解鎖

你目前沒有任何已儲存的模型（可能剛才把最後一組刪掉了），所以沒有東西可以解鎖。清除密碼後就能直接進去重新新增模型。

照片、衣櫃、成品都不會被刪，只會清掉解鎖密碼。

虛擬試穿・靜態版

上傳全身照、從衣櫃挑 1–3 件衣服，用你自己儲存的廠商 API 直接在瀏覽器裡合成試穿圖。這個版本不需要後端，整個程式就是這一個 HTML 檔，可以打包帶走、放到 GitHub Pages／Cloudflare Pages／Vercel 上開來用。

先講清楚三件事：

1．資料只存在這台裝置的瀏覽器裡（照片存 IndexedDB、設定存 localStorage）。換瀏覽器、換裝置或清除瀏覽器資料，照片和設定就不見了，要重新上傳、重新填金鑰。原本那個 App 裡的照片、衣櫃、模型設定不會自動帶過來，這一版從空白開始。

2．靜態版沒有 Muse 內建生圖。生成時是瀏覽器拿你的照片和金鑰，直接去叫你選的那家廠商 API，所以要先在下面「模型設定」存好至少一組模型才能生成；還沒存的話，生成按鈕會引導你先新增。

3．在中國能不能連上，取決於部署網址和廠商：github.io 通常打得開，workers.dev／vercel.app 常被擋；OpenAI、Google、Meta 的 API 在中國連不上，智譜連得上但它的生圖接口只吃文字、不能拿照片試穿（見模型清單標示）。做好後請在當地實際開一次、跑一張圖確認。

下載回去就是完整程式，解壓／部署都不需要後端；放到任何靜態空間就能用。

1．人物照片

點照片庫裡的任一張，設為目前要試穿的底圖；也可以生成下面的「多角度底圖」來用。
還沒有選照片，先從下面上傳一張全身照。

照片庫 0 / 15 張（可多選上傳，每張可逐張刪除）

2．衣櫃

直接點照片就是選來試穿，再點一下取消，一次最多 3 件；照片下方的「複製這件」會再產生一件，方便同款不同色。每件都可再編輯品牌、名稱、分類、價格、網址、備註或換照片。

已選來試穿：0 / 3 件

衣櫃還是空的，用上面上傳照片或貼連結新增第一件。

3．試穿

用目前的人物底圖 ＋ 衣櫃選好的 1–3 張照片合成：衣櫃照片裡 MODEL 身上穿的整套上下身（含洋裝、外套、鞋子），會換到底圖那個人身上。單張生活照當底圖時會保留原背景；用多角度底圖時是素色背景。

尚未選底圖與衣服。

使用中的模型：（尚未設定）

這次要用的照片

還沒選底圖與衣服：先到「1．人物照片」選一張，再到「2．衣櫃」點照片選要試穿的 1–3 件。

這裡寫的會附加在預設指令後面，不會蓋掉「保留臉部、髮型、姿勢與身形」那些要求。確認上面的照片都對，再按開始試穿。

試穿紀錄

還沒有成品，選好底圖和衣服後按「開始試穿」。

4．全身多角度底圖

用目前的人物照片一次合成 3 組、每組四個角度（正面／斜前方／側面／背面，素色背景）。點任一組裡的任一張，就選定整組當試穿底圖；有 2 組以上時可以自組一組。中途有幾張失敗的話，按「重試失敗的角度」只補缺的那幾張，不會整組重跑。

自組一組

每個角度各挑一張（來自不同組也可以），組成你自己的一組底圖。

5．模型設定（BYOK）

先選廠商、再挑模型，接口地址會自動帶入預設值（可以手動改），填 API KEY 按儲存就好。金鑰只存在你的瀏覽器，畫面上只顯示星號加末四碼。

設定解鎖密碼

你已經存了第一組模型，現在設一組密碼。之後每次開啟這個程式，都要先選一組已存模型、輸入這組密碼才能用；切換或刪除模型也要再輸入一次。密碼只存雜湊，程式本身看不到原文。忘記密碼只能重置，重置會清除全部已存模型設定。

正在編輯已儲存的模型

Cloudflare 的 API 不接受瀏覽器直接呼叫（跨域被擋），要透過你自己部署的 Worker 轉一手。留空就是直接呼叫，會出現 Failed to fetch。

已儲存的模型

還沒存任何模型。先在上面選廠商、挑模型、貼 API KEY 按儲存——存好第一組之後會請你設定解鎖密碼。

測試連線

用「使用中的模型」實測一次：先分辨「網路根本連不到」和「瀏覽器跨域被擋」這兩種完全不同的失敗，再對真正的接口位址發一次假金鑰的請求（不會產生費用）。改完模型、或生成失敗想確認是哪一段出問題時用。
