登入

每一台裝置各自保存資料，每個人有自己的衣櫃、成品與模型設定。

　

第一次用雲端、或昨天只用過本機帳號的話，請按上面的「建立一個」用同一組 Email 重建，本機資料會一起搬上去。

每次開啟都要重新登入；同一台裝置換人使用時，上一個人的資料會立刻從畫面清掉。換手機或電腦請用「設定」頁的備份檔搬過去。

刪除帳戶

輸入 Email 和密碼確認身份。會永久刪除雲端帳號與所有雲端資料（照片、衣櫃、成品、多角度、模型），無法復原。這台裝置的本機資料會保留。

重設密碼

輸入你註冊的 Email，會寄一封 6 位數驗證碼。

重設後照片、衣櫃、成品會保留；模型 API KEY 因為是用舊密碼加密的，需要重新輸入。

先選模型、輸入密碼

這個靜態版每次開啟都要先解鎖：選一組你已經儲存的模型，輸入你的密碼，才能開始使用。金鑰只會送到你選的那家廠商，不會經過任何其他伺服器。

忘記密碼只能重置：重置會清除全部已存的模型設定與金鑰（照片與衣櫃不會被刪），之後要重新新增模型、重新設密碼。

沒有模型可以解鎖

你目前沒有任何已儲存的模型（可能剛才把最後一組刪掉了），所以沒有東西可以解鎖。清除密碼後就能直接進去重新新增模型。

照片、衣櫃、成品都不會被刪，只會清掉解鎖密碼。

先講清楚三件事：

1．資料只存在這台裝置的瀏覽器裡（照片存 IndexedDB、設定存 localStorage）。換瀏覽器、換裝置或清除瀏覽器資料，照片和設定就不見了，要重新上傳、重新填金鑰。原本那個 App 裡的照片、衣櫃、模型設定不會自動帶過來，這一版從空白開始。

2．靜態版沒有 Muse 內建生圖。生成時是瀏覽器拿你的照片和金鑰，直接去叫你選的那家廠商 API，所以要先在「API模型」頁存好至少一組模型才能生成；還沒存的話，生成按鈕會引導你先新增。

3．在中國能不能連上，取決於部署網址和廠商：github.io 通常打得開，workers.dev／vercel.app 常被擋；OpenAI、Google、Meta 的 API 在中國連不上，智譜連得上但它的生圖接口只吃文字、不能拿照片試穿（見模型清單標示）。做好後請在當地實際開一次、跑一張圖確認。

新增或編輯模型

先選廠商、再挑模型，接口地址會自動帶入預設值（可以手動改），填 API KEY 按儲存就好。金鑰只存在你的瀏覽器，畫面上只顯示星號加末四碼。

設定解鎖密碼

你已經存了第一組模型，現在設一組密碼。之後每次開啟這個程式，都要先選一組已存模型、輸入這組密碼才能用；切換或刪除模型也要再輸入一次。密碼只存雜湊，程式本身看不到原文。忘記密碼只能重置，重置會清除全部已存模型設定。

正在編輯已儲存的模型

留空就自動找名稱有 9B 的模型；選了會用同一組金鑰一起存成高畫質模型。

Cloudflare 的 API 不接受瀏覽器直接呼叫（跨域被擋），要透過你自己部署的 Worker 轉一手。留空就是直接呼叫，會出現 Failed to fetch。

已儲存的模型

還沒存任何模型。先在上面選廠商、挑模型、貼 API KEY 按儲存——存好第一組之後會請你設定解鎖密碼。

測試連線

用「使用中的模型」實測一次：先分辨「網路根本連不到」和「瀏覽器跨域被擋」這兩種完全不同的失敗，再對真正的接口位址發一次假金鑰的請求（不會產生費用）。改完模型、或生成失敗想確認是哪一段出問題時用。
